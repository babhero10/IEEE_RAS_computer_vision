# Exercises — warm up before the assignment

Six small, self-checking files. Each one has a few `TODO`s; fill them in
and run the file directly (e.g. `python ex1_functions.py`). If everything
is correct it prints `all checks passed!`. If something is wrong, an
`AssertionError` tells you which check failed.

Work through them in order — they build up from plain functions to
classes with attributes and methods, and end with using a standard
library inside a class (same idea the assignment uses with OpenCV).

1. `ex1_functions.py` — basic functions, return values.
2. `ex2_strings.py` — functions that work with strings, loops.
3. `ex3_simple_class.py` — your first class: attributes + one method.
4. `ex4_class_methods.py` — a class with several methods that change
   its state.
5. `ex5_class_practice.py` — a class with multiple attributes and
   methods that depend on each other.
6. `ex6_library_practice.py` — a class that uses the `math` library.

Solutions live in `../soluations/exercises/` (not part of the repo — for
your own reference after you've had a try).
